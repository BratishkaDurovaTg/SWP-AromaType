# LLM Usage Report

## AI/LLM Tools Used

* ChatGPT (OpenAI)

## Purpose of Use

During Assignment 5, ChatGPT was used as a supporting tool for documentation work. AI assistance was used to:

* improve the wording, structure, and readability of project documentation;
* assist with drafting documentation based on the team's completed work;
* review documentation against the Assignment 5 requirements and identify missing or incomplete sections;
* improve the clarity and grammar of English documentation.

## Human Contribution

All technical implementation, software development, testing, Sprint activities, project decisions, customer communication, and repository management were completed by the team members.

All documentation was reviewed, edited, and verified by the team before submission.
