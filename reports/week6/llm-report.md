# LLM Usage Report

## AI/LLM Tools Used

- ChatGPT (OpenAI)

## Purpose of Use

During Assignment 6 (Week 6), ChatGPT was used as a supporting tool for documentation and report preparation. AI assistance was used to:

- improve the wording, structure, and readability of project documentation;
- assist with drafting documentation based on the team's completed work;
- review documentation against the Assignment 6 requirements and identify missing or incomplete sections;
- improve the clarity and grammar of English documentation;
- help organize public reports and repository documentation.

## Human Contribution

All technical implementation, software development, testing, Sprint activities, project planning, customer communication, deployment, and repository management were completed by the team members.
All documentation was reviewed, edited, and verified by the team before submission. AI-generated suggestions were used only as writing and documentation review assistance.
